## ✨ Key Features

  | Feature | Description |
  | :--- | :--- |
  | 🤖 **Single Player vs Bot** | Play against a computer opponent with timed move delays. |
  | 🎨 **Theme & Styling** | Custom cherry-red and cream theme styled with CSS Variables. |
  | 🎯 **Player Selection** | Choose your starting mark (**X** or **O**) before the match starts. |
  | 🎆 **Celebration Effects** | Visual win highlights and integrated celebration feedback. |
  | 🔄 **Instant Restart** | One-click board reset to quickly play again. |
  | 📱 **Responsive Design** | Clean grid layout that scales smoothly across screens. |

</div>

## 🛠️ Tech Stack & Tools

  <img src="https://skillicons.dev/icons?i=html,css,js,vscode,git,github" alt="Tech Stack Icons" />

  * **HTML5** – Structured semantic layout and grid container elements.
  * **CSS3** – Custom properties (Variables), Flexbox, CSS Grid, and dynamic hover effects.
  * **JavaScript (ES6+)** – DOM manipulation, game-state management, win-condition matching, and asynchronous delay timing (`setTimeout`).

## 🚀 How to Run Locally

  1. **Clone the repository:**
     ```bash
     git clone [https://github.com/your-username/tic-tac-toe.git](https://github.com/your-username/tic-tac-toe.git)
     ```

  2. **Navigate into the project directory:**
     ```bash
     cd tic-tac-toe
     ```

  3. **Launch the project:**
     Open `index.html` directly in your browser or use VS Code's **Live Server** extension.
